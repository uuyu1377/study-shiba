# 讀書柴犬 2.0

繁體中文的任務規劃與專注陪讀工具。HTML、CSS、JavaScript 與柴犬 SVG 全部內嵌於根目錄 `index.html`，無後端、外部資源、套件或 API。下載後可直接以瀏覽器開啟。

- 網站：https://uuyu1377.github.io/study-shiba/
- 任務新增、編輯、刪除、完成／取消完成，自訂科目。
- 優先順序、截止日期、逾期提示、關鍵字搜尋、科目及狀態篩選、建議／新增／截止日排序。
- 1～60 分鐘計時，15／25／50 分鐘快捷鍵；從任務啟動專注、自動帶入科目。
- 暫停、繼續、重設、五分鐘休息；只累積專注時間，分頁標題顯示倒數。
- 每日目標（5～480 分鐘）、近七天圖表、各科目歷史統計。
- 柴犬改名、狀態互動、五項永久保留的成就。
- 本機保存、舊版資料相容、JSON 備份匯出／檢查／確認匯入（上限 2 MB）。

## 使用方式

新增任務，設定科目、優先順序與選填日期；用搜尋、篩選、排序挑選任務。按任務「專注」會用目前設定分鐘數開始計時。完成計時後由使用者決定是否休息，任務仍需自行勾選完成。

未完成任務優先；「建議順序」再依優先順序、截止日排列。「截止日優先」則依日期排列，無日期置後；「新增順序」保留原序。搜尋與篩選不影響全部任務的完成比例。

## 保存與限制

資料保存在目前瀏覽器的 localStorage，維持 `study-shiba.v2` 儲存鍵以讀取舊資料，新欄位提供預設值。更新同一 GitHub Pages 網址時可讀取舊版紀錄；換瀏覽器、換網址或清除網站資料不會自動同步，請定期備份。

匯入採取代方式；先檢查、看摘要，再確認取代，不會合併。取消或無效檔案不變更紀錄，無法寫入 localStorage 時也不取代。專注、暫停及休息時不能匯入。

重新整理後計時器待機，網頁關閉期間不累積。背景網頁依經過時間補算到本輪上限，並不驗證使用者是否真的在讀書。請使用單一分頁計時；未提供多分頁寫入鎖定、帳號、雲端同步或推播。

## 驗證

Node.js 18 以上可執行，不需安裝依賴：

```sh
node --test tests/core.test.mjs
```

23 項測試直接讀取 `index.html` 的核心邏輯，涵蓋資料相容、任務篩選與排序、時間與成就門檻、跨日／跨月、備份往返和錯誤拒絕。瀏覽器操作、重新整理及 390／320 像素寬視窗另行檢查；窄視窗驗證不等於所有實體手機或瀏覽器的相容性驗證。
